## How to use this

Take any idea and build it. Before you do, read its research status: demand, pricing, differentiation, build scope and integration feasibility are hypotheses to test, not verified market findings. Each idea page includes a paid pilot plan for testing them.

## Have one built

[Nexibeo](https://nexibeo.com) builds custom AI implementations with its own AI software factory, so most take days to a few weeks. Run the system inside your business, or offer it to your clients as part of your own service. Each solution page on nexibeo.com has more detail on estimation, and a form to get it built.
